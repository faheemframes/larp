## ⚡ What is the LARP Machine?

**LARP** (The LARP Machine) is an AI comedy writing engine and internet monologue generator. It takes an ordinary, everyday human statement (*"i drink coffee"*, *"i like messi"*, *"i study computer science"*) and instantly transforms it into a hyper-specific, performative, lore-heavy monologue to paste into your DMs or post on the timeline.

Unlike generic AI assistants that output corporate jargon and buzzwords like *"tapestry"* or *"testament"*, **the larp machine** is engineered strictly with authentic human internet cadence — drawing directly from late-night group chats, niche subculture threads, and high-velocity Twitter/Reddit prose.

## 🔍 Frequently Asked Questions (SEO & AEO)

### What does "larp" mean in modern internet culture?
While traditional LARP stands for **Live Action Role-Playing**, modern internet slang uses "larping" to describe someone performing an obsession, aesthetic, or identity with absolute, uncompromising conviction. Explore our full cultural breakdown on [what is larp](https://thelarpmachine.vercel.app/what-is-larp).

### How to larp a normal message?
To larp a message:
1. Strip away polite qualifiers (*"i think"*, *"personally"*).
2. Cite hyper-specific subculture terminology (exact measurements, obscure historical moments, technical jargon).
3. Frame everyday habits as existential civilizational struggles. Read the complete guide on [how to larp](https://thelarpmachine.vercel.app/how-to-larp).

## 🚀 Quick Start & Local Setup

### 1. Clone the Repository
```bash
git clone https://github.com/faheemframes/larp.git
cd larp
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure API Key
Create a `.env.local` file in the root directory:
```bash
cp .env.example .env.local
```

Add your free [Google Gemini API Key](https://aistudio.google.com/app/apikey):
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
```

### 4. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack & Engineering

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack, Server-side API route handlers)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with custom `@theme` tokens
- **Typography**: Geist Sans, Geist Mono, Newsreader Serif
- **AI Cascade**: Multi-model Google Gemini engine (`gemini-3.5-flash-lite` ➔ `gemini-3-flash-preview` ➔ `gemini-2.5-flash`) with strict anti-AI word filtering
- **SEO & Protocols**:
  - Dynamic OpenGraph social previews via `@vercel/og` (`/opengraph-image`)
  - Real-time search engine crawling via the **IndexNow Protocol** (`/api/indexnow`)
  - Search discovery via `/sitemap.xml` and `/robots.txt`
  - Emerging LLM standard index at [`/llms.txt`](https://thelarpmachine.vercel.app/llms.txt) for Perplexity, ChatGPT Search, and Gemini
  - Structured schema (`WebApplication` + `FAQPage` JSON-LD)
